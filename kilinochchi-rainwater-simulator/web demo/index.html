About and how to use

Set at least three household parameters. The page first simulates one warm-up year so storage carries into the scored year, then animates the next 365 days. Start begins or resumes, Pause holds the run and Reset clears it. Changing a parameter resets the run.

For the fitted seasonal model, load the calibration CSV created by the Colab notebook. It supplies the 12 monthly wet-after-dry and wet-after-wet probabilities and shifted-gamma parameters. Without that file, the page uses clearly labelled illustrative parameters.

Model scope and limits

The fitted mode uses a month-dependent two-state Markov chain for wet/dry occurrence. A wet day has rainfall equal to 1 mm plus a gamma-distributed excess, matching the notebook's calibrated rainfall model. The model collects runoff, spills water above capacity, then serves daily demand. Reliability is the fraction of scored-year days when full demand is met.

This page shows one stochastic year, while notebook results use 200 replications and report confidence intervals. The browser and NumPy use different random-number generators, so annual results will differ. Use the notebook for reported estimates and uncertainty. Roof area, efficiency and demand remain scenario assumptions.
