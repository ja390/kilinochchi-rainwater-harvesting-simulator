# User guide

## Open the simulator

Open the [live simulator](https://ja390.github.io/kilinochchi-rainwater-harvesting-simulator/kilinochchi-rainwater-simulator/web%20demo/index.html) in a current browser. For local use, open `web demo/index.html`. The demo uses standard browser APIs and needs no server or third-party library.



## Inputs

| Input | Meaning |
|---|---|
| Tank capacity | Maximum stored water, in m³ |
| Roof catchment | Area draining to the tank, in m² |
| Daily demand | Household demand, in m³/day |
| Collection efficiency | Fraction of roof rainfall collected, from 0 to 1 |
| Browser random seed | Integer seed for a repeatable browser sequence |

For the notebook-fitted seasonal model, select the calibration CSV generated by the Colab notebook. The file contains 12 monthly rows with wet-after-dry and wet-after-wet probabilities and shifted-gamma parameters. Without it, the demo clearly labels its parameters illustrative.

## Controls and outputs

- **Start** begins the warm-up and scored simulation, or resumes a paused run.
- **Pause** stops the animation while retaining results.
- **Reset** clears the current simulation.
- **Run reference check** compares a fixed eight-day sequence with the notebook's deterministic benchmark.
- The scored-year cards show fully supplied days, day-based reliability, storage, shortage and overflow. The chart shows storage through the scored year.

Changing an input resets the current run. The warm-up year initializes storage; results are calculated for the following 365 days.

## Interpretation

The browser runs one stochastic year. The notebook runs 200 replications and reports a mean and confidence interval. Browser and NumPy random-number generators differ, so their rainfall sequence and annual reliability will not match. The reference check verifies only deterministic water-balance calculations. Use the notebook for reported estimates and uncertainty.

Rainfall data are gridded estimates; roof area, collection efficiency and demand are scenario assumptions. The simulator is for scenario comparison, not a household installation recommendation.
